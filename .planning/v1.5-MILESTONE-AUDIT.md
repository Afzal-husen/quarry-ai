## 5. Tech Debt & Known Gaps

| Item | Severity | Notes |
|------|----------|-------|

| `test_query_stream_with_session_writes_to_history` verifies token chunks separately, not full assembled string | Low | SSE splits tokens across events; test correctness is sufficient but assertion pattern differs from sync endpoint test. |
| `generate_session_title()` shares the same `GroqConnectionManager` singleton as answer generation | Low | Works correctly but could benefit from a dedicated faster/cheaper model config in future. |

**No HIGH severity tech debt items.**
