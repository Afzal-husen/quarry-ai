# Plan 21-01: Query Condensation & Conversational Retrieval

## Goal

Implement LLM-based query condensation to rewrite conversational user follow-up questions into standalone queries based on past session messages.

## Requirements Addressed

- **MEM-03**: LLM-based query condensation (standalone query generation from follow-up and history).

## Success Criteria

1. A LangChain chain dynamically rephrases follow-up queries using the last 5 turns of message history.
2. If message history is empty, the LLM condensation step is bypassed.
3. If the LLM condensation chain fails, it falls back to the user's raw query and logs a warning.
4. All unit and integration tests run successfully.
