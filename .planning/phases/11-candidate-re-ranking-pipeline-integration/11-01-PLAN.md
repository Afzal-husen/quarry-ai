# Plan 11-01: Build Flashrank singleton model cache, integrate into QAPipeline, and verify citations formatting

## Goal
Load the local FlashRank reranking engine on CPU as a cached singleton, compress candidate documents using ContextualCompressionRetriever, and integrate them into the FastAPI query and citations pipeline without cross-tenant leakage or database connection locks.

<threat_model>
- **Threat**: Cross-tenant data leakage via compressed retrieval.
- **Mitigation**: FlashRank compressor runs on the documents retrieved from the base hybrid retriever. The base hybrid retriever strictly enforces user-tenant isolation on the chunks JSON cache and Chroma DB directory path (`backend/data/vectorstore/{user_id}/{document_uuid}`).
- **Threat**: Memory bloat / reload latency leading to Denial of Service (DoS) or resource exhaustion.
- **Mitigation**: Model weights are cached using a thread-safe singleton manager class (`RerankManager`) initialized lazily under lock protection, ensuring the ONNX model is loaded exactly once across all query execution threads.
</threat_model>
