<task type="auto">
  <name>Task 2: Integrate Summarizer into Background Ingestion Job</name>
  <files>backend/app/routes/upload.py</files>
  <read_first>backend/app/routes/upload.py</read_first>
  <action>
    Modify `run_ingestion_job` in `backend/app/routes/upload.py`:
    - After vector indexing completes (Step 4), open the generated chunks JSON file from `CHUNKS_DIR / user_id / f"{document_id}.json"`.
    - Set `"summary_status": "pending"` initially.
    - Extract `"parents"` list from the JSON payload.
    - Join parent texts. If the total character length of the combined parent texts exceeds 10,000 characters, truncate by taking only the first 5 parent chunk texts.
    - Invoke `DocumentSummarizer.summarize_text()` on the combined/truncated text.
    - Update the JSON metadata payload with the generated `"summary"` and set `"summary_status"` to `"completed"`.
    - If summarization raises an exception, catch it, log the error, and update the JSON payload with `"summary": ""` (or `null`) and `"summary_status": "failed"`.
    - Save the updated JSON payload back to the metadata file.
    - Do NOT let summarization failure bubble up to trigger ingestion rollback.
  </action>
  <verify>
    Run backend tests to ensure ingestion still works and metadata JSON has summary keys.
  </verify>
  <acceptance_criteria>
    - `backend/app/routes/upload.py` has try-catch wrapping the summarization step.
    - Output chunks JSON file contains `"summary"` and `"summary_status"`.
  </acceptance_criteria>
  <done>Summarization integrated inline in background ingestion task.</done>
</task>
