<objective>
Implement the backend foundation for user-guided focus summaries of documents. This includes extending the core `DocumentSummarizer` with a topic-specific summarization method, creating a FastAPI route `/documents/{document_id}/summary/guided`, implementing keyword-based chunk pre-filtering, and adding validation and unit/endpoint tests.

Purpose: Allow users to request custom summaries about specific topics, keeping it fast and non-blocking.
Output: Extended core/summarizer.py, routes/documents.py, and new tests.
</objective>

<task type="auto">
  <name>Task 2: Implement FastAPI endpoint POST /documents/{document_id}/summary/guided</name>
  <files>backend/app/routes/documents.py</files>
  <read_first>backend/app/routes/documents.py</read_first>
  <action>
    1. Define Pydantic request model:
       ```python
       class GuidedSummaryRequest(BaseModel):
           focus_topic: str = Field(..., description="The topic to focus the summary on.")
       ```
    2. Define Pydantic response model:
       ```python
       class GuidedSummaryResponse(BaseModel):
           guided_summary: str = Field(..., description="The generated focused summary.")
       ```
    3. Add a new POST route `/{document_id}/summary/guided`:
       - Requires `Depends(get_current_user)` for JWT protection.
       - Validates `document_id` is a valid UUID string (raise HTTP 422 on failure, matching other route validation patterns).
       - Validates `request.focus_topic` is non-empty and len <= 200 (raise HTTP 400 with a detailed error message on failure).
       - Resolves `user_id = current_user["id"]` and checks if the document chunks metadata file `CHUNKS_DIR / user_id / f"{document_id}.json"` exists (raise HTTP 404 if missing).
       - Loads the chunks metadata JSON.
       - Extracts `parents = payload.get("parents", [])`.
       - Applies keyword pre-filter: select parents whose `text` contains the `focus_topic` case-insensitively.
       - If no chunks match the topic, return HTTP 200 immediately with `{ "guided_summary": f'No content found related to "{focus_topic}".' }`.
       - Otherwise, join the matched parent chunk texts with `\n\n` and truncate to the first 5 matching parents (max 10k chars).
       - Wrap the synchronous `summarizer.summarize_with_focus()` call in `asyncio.to_thread()` to prevent blocking the event loop:
         ```python
         summarizer = DocumentSummarizer()
         summary_text = await asyncio.to_thread(summarizer.summarize_with_focus, combined_text, request.focus_topic)
         ```
       - Return `GuidedSummaryResponse` with `guided_summary=summary_text`.
  </action>
  <verify>Run FastAPI dev server or test client calls to confirm output.</verify>
  <acceptance_criteria>
    - `backend/app/routes/documents.py` implements `@router.post("/{document_id}/summary/guided", response_model=GuidedSummaryResponse)`
    - Empty topic query or topic > 200 chars returns HTTP 400.
    - Missing document metadata returns HTTP 404.
    - Topics with no matching keyword text return HTTP 200 with the soft fallback message.
    - Synchronous LLM call runs via `asyncio.to_thread`.
  </acceptance_criteria>
  <done>Endpoint is fully implemented, authenticated, validated, and non-blocking.</done>
</task>
