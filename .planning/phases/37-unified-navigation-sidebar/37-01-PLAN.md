# Plan 37-01: Implement unified collapsible navigation sidebar component and integrate across Dashboard and Chat

## Goal
Create a shared, highly responsive, and collapsible navigation sidebar component (`Sidebar.tsx`) that merges the application links, user profile details, settings control (Theme Toggle), and the conversation history list into a single sidebar, integrating it into both the dashboard and chat feed layouts.

<threat_model>
- **Threat**: Cross-tenant chat history leakage if the session list is requested without proper authorization.
- **Mitigation**: The API client automatically appends the user's JWT Bearer token to requests. The backend session routes isolate data based on the authenticated user ID. In the frontend, the sidebar fetches sessions lists using the same client to guarantee a user only sees their own conversations.
</threat_model>
