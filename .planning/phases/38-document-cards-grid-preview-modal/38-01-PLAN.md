# Plan 38-01: Redesign Dashboard to Document Card Grid and implement Multi-Format Preview Modal

## Goal
Redesign the file listing interface on the dashboard to use modern, responsive document preview cards with hover transitions and status indicators. Build a fullscreen, fully immersive preview overlay component (`PreviewModal.tsx`) to render PDF embeds (via Blob Object URLs) and scrollable page-by-page sheet views for Word files.

<threat_model>
- **Threat**: Token leakage in server logs or browser history if query parameters are used to authorize document previews.
- **Mitigation**: Fetch PDF files asynchronously with the JWT token in request headers (`Authorization: Bearer <token>`), load binary data into memory as a Blob, and use local Object URLs (`URL.createObjectURL(blob)`) for `<iframe src={objectUrl}>` rendering. Revoke Object URLs upon component unmount to protect client resources.
</threat_model>
