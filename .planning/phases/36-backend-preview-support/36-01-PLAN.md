# Plan 36-01: Expose endpoints to serve raw document files and chunk metadata JSON with tenant guards

## Goal
Implement backend API endpoints under the `/documents` router to retrieve raw uploaded document files and get the pre-parsed text chunk metadata, securing them with JWT authentication and strict multi-tenancy ownership checks.

<threat_model>
- **Threat**: Cross-tenant data disclosure. A user retrieves files or chunk metadata belonging to another user by guessing the document UUID.
- **Mitigation**: Authenticate endpoints using the standard `current_user` JWT dependency. Ensure the target document exists under the user's workspace folders (`data/uploads/{user_id}/` or `data/chunks/{user_id}/`). Return 403 Forbidden for cross-tenant attempts and 404 Not Found for non-existent document IDs.
</threat_model>
