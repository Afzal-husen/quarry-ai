# Plan 10-01: Build dynamic BM25 initialization, construct EnsembleRetriever, and verify tenant isolation

## Goal
Implement a local hybrid search combining lexical BM25 matching and dense vector search, ensuring tenant isolation.

<threat_model>
- **Threat**: Cross-tenant data leakage via BM25 retrieval.
- **Mitigation**: BM25 retriever loads documents dynamically only from the authenticated user's chunks folder `backend/data/chunks/{user_id}/{document_uuid}.json`. The query route checks ownership early via `data/vectorstore/{user_id}/{document_id}` path existence.
</threat_model>

<id>10-01-02</id>
<type>execute</type>
<description>Implement dynamic BM25 initialization and EnsembleRetriever in vectorstore.py</description>
<read_first>
- backend/app/core/vectorstore.py
</read_first>
<action>
Import BM25Retriever from langchain_community.retrievers and EnsembleRetriever from langchain.retrievers.
Implement get_hybrid_retriever(self, user_id: str, document_id: str, top_k: int = 3) on VectorStoreManager:
  1. Load chunks from backend/data/chunks/{user_id}/{document_id}.json. If file missing, raise VectorStoreError.
  2. Map chunk list to standard langchain Document objects, passing page_index and source_filename in metadata.
  3. Preprocess text chunks: lowercase and split by whitespace and basic punctuation using re.findall(r'\w+', text.lower()).
  4. Instantiate BM25Retriever from documents, passing preprocess_func. Set its search kwarg k to top_k.
  5. Load vector store retriever via self.get_retriever(user_id, document_id, top_k).
  6. Read HYBRID_LEXICAL_WEIGHT and HYBRID_SEMANTIC_WEIGHT environment variables, falling back to 0.5.
  7. Construct and return EnsembleRetriever combining the BM25 and vector retrievers with the resolved weights.
</action>
<acceptance_criteria>
- get_hybrid_retriever is defined on VectorStoreManager.
- It parses chunks correctly and raises VectorStoreError if chunks are missing.
- It instantiates BM25Retriever with case-insensitive tokenization preprocessing.
- It builds EnsembleRetriever combining both retrievers with weights loaded from env variables.
</acceptance_criteria>
</task>
