# Plan 28-01: Next.js Proxy & Authentication Guard Stabilization

## Goal

Move the `proxy.ts` request interceptor to the correct Next.js 16 directory (`frontend/src/proxy.ts`), export the expected functions and configurations, and verify route redirections work seamlessly.

## Requirements Addressed

- **REQ-DBG-01 (Next.js Middleware/Proxy Location)**: Relocate `proxy.ts` to `frontend/src/proxy.ts`.
- **REQ-DBG-02 (Enforce Redirections)**: Implement token cookie checking and redirect logic.
- **REQ-DBG-03 (Build & Compilation Guard)**: Ensure clean frontend typescript build.

## Success Criteria

1. Next.js `proxy.ts` is moved to `frontend/src/proxy.ts` so Next.js 16 can locate and execute it.
2. Route protections (`/` and `/chat`) correctly redirect unauthenticated users to `/login`.
3. Auth routes (`/login` and `/register`) correctly redirect authenticated users to `/`.
4. The frontend builds cleanly and the application has no TypeScript compilation errors.
