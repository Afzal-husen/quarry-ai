<task type="auto">
  <name>Task 2: Author backend/Dockerfile</name>
  <files>backend/Dockerfile</files>
  <action>
    Create a `Dockerfile` in the `backend/` directory:
    - Base Image: Use `python:3.14-slim` or a stable Python 3.14 base image.
    - Installation of uv: Install `uv` (using `pip install uv` or the official installer script) to handle dependencies.
    - Dependencies: Copy `pyproject.toml` and `uv.lock` (if exists) and run `uv pip install --system -r pyproject.toml` or `uv sync` equivalents to build standard system environment packages.
    - Working Directory: `/app`
    - Source: Copy backend source code files into `/app`.
    - Port: Expose port 8000.
    - Environment Variables: Set `DATA_DIR=/app/data` default. Set `PYTHONUNBUFFERED=1`.
    - Startup Command: Run `python main.py` or use uvicorn command.
    - Non-root User: Create a system group and user and change ownership of `/app` to run as non-root user. Make sure the `/app/data` folder is created and writable by this user.
  </action>
  <verify>
    Run a docker build command on the Dockerfile.
  </verify>
  <acceptance_criteria>
    - `backend/Dockerfile` builds successfully.
    - The output image runs Python 3.14.
  </acceptance_criteria>
  <done>Created and tested backend/Dockerfile</done>
