# Plan 39-01: Implement Chat Input Context Popover Menu, Selection Modal, and Active Context Badges

## Goal
Implement a premium document context scoping flow inside the Chat view. Add a Plus icon menu button inside the input panel, triggering a popover option to open a document selection checklist Dialog modal. Show active context documents as dismissible badges above the input box, and support inline previewing of checklist documents via `PreviewModal`.
