  <files>backend/app/routes/documents.py</files>

  <action>
    Add new endpoints under the documents router:
    - `GET /{document_id}/summary`:
      - Validates JWT authorization using `current_user: dict = Depends(get_current_user)`.
      - Checks if `CHUNKS_DIR / user_id / f"{document_id}.json"` exists. If not, raises `HTTP 404`.
      - Reads the JSON file and returns `{"document_id": document_id, "summary": payload.get("summary", ""), "summary_status": payload.get("summary_status", "pending")}`.
    - `POST /{document_id}/summary/regenerate`:
      - Validates authorization using `current_user`.
      - Checks if `CHUNKS_DIR / user_id / f"{document_id}.json"` exists. If not, raises `HTTP 404`.
      - Updates `"summary_status"` to `"pending"` and writes the file.
      - Dispatches a background helper task `run_regeneration_job` via `background_tasks: BackgroundTasks` parameter.
      - Returns `{"document_id": document_id, "status": "pending"}` with `HTTP 202`.
      - Define helper function `run_regeneration_job(user_id, document_id)` that reads the chunks file, extracts parent chunks, truncates if necessary (>10,000 chars to first 5 parent chunks), invokes `DocumentSummarizer.summarize_text()`, and saves the resulting summary and `"completed"` / `"failed"` status back to the JSON file.
  </action>
  <verify>

  </verify>
  <acceptance_criteria>

    - POST regenerate is non-blocking (runs via BackgroundTasks) and updates metadata status.
  </acceptance_criteria>
