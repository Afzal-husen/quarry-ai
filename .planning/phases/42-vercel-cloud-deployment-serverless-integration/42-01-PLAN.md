# Plan 42-01: Vercel Frontend Deployment & Backend Hosting Preparation

**Phase**: 42 — Vercel Cloud Deployment & Serverless Integration
**Milestone**: v7.0
**Requirements**: BE-DEPLOY-01, BE-DEPLOY-02, BE-DEPLOY-03, FE-DEPLOY-01

## Context Summary

> ⚠️ **Important**: Vercel's serverless filesystem is ephemeral. The current backend uses local SQLite + disk-based Chroma — both require persistent storage incompatible with Vercel Serverless functions. This plan deploys the **Next.js frontend to Vercel** and prepares the **FastAPI backend for a persistent host** (Railway, Render, or local). Full cloud storage migration is deferred to v8.0.

## Tasks

### Wave 1 — Backend: Environment-Driven Configuration

**Task 1.1 — Make CORS origins configurable via environment variable**

File: `backend/main.py`

Currently `allow_origins=["http://localhost:3000"]` is hardcoded. Change to read from `CORS_ORIGINS` env var:

```python
import os

# Reads comma-separated production origins, falls back to localhost for dev
_raw_origins = os.getenv("CORS_ORIGINS", "http://localhost:3000")
ALLOWED_ORIGINS = [o.strip() for o in _raw_origins.split(",") if o.strip()]

app.add_middleware(
    CORSMiddleware,
    allow_origins=ALLOWED_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**Task 1.2 — Update `.env.example` with new variables**

File: `backend/.env.example`

Add:
```
# CORS: comma-separated list of allowed frontend origin URLs
CORS_ORIGINS="http://localhost:3000"

# JWT signing secret (generate a random 64-char string for production)
JWT_SECRET_KEY="change-me-in-production"
```

**Task 1.3 — Generate `requirements.txt` from pyproject.toml**

File: `backend/requirements.txt` (new)

Run `uv export --no-hashes --format requirements-txt` to generate a flat requirements file that Vercel (and other PaaS hosts like Railway/Render) can use with standard `pip install`.

Command to run:
```bash
cd backend && uv export --no-hashes --format requirements-txt -o requirements.txt
```

**Task 1.4 — Add `[tool.vercel]` entrypoint in pyproject.toml**

File: `backend/pyproject.toml`

Add entrypoint so Vercel can locate the FastAPI `app` object even from a subdirectory:
```toml
[tool.vercel]
entrypoint = "main:app"
```
