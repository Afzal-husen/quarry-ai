# Plan 12-01: Implement list, delete, and reindex endpoints under documents.py with tenant ownership guards

## Goal
Expose REST API endpoints to list, delete, and re-index uploaded documents per authenticated user, cleaning up all stored chunks, vector database files, and uploaded raw files on disk.

<threat_model>
- **Threat**: Cross-tenant data tampering or deletion of documents.
- **Mitigation**: Every endpoint verifies document ownership by checking if the requested document ID has its metadata/chunks inside `backend/data/chunks/{user_id}/{document_id}.json` or under the user's upload folder. A 403 Forbidden is returned if the document belongs to another user, and a 404 Not Found if it does not exist at all.
</threat_model>
