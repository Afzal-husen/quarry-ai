# Plan 19-01: Advanced Chunking Strategies

## Goal

Add semantic chunking as a configurable upload strategy, implement the parent-document retriever pattern to search on child chunks and return parent contexts, and allow configuring the sliding window overlap size via query parameters.

## Requirements Addressed

- **CHUNK-01**: Semantic chunking strategy is available as a configurable option per upload.
- **CHUNK-02**: Parent-document retriever pattern (index children, return parent context to LLM).
- **CHUNK-03**: Sliding window overlap size is configurable per upload request.

## Success Criteria

1. `/upload` and `/reindex` endpoints accept optional query parameters `chunking_strategy` (character/semantic), `chunk_overlap`, `semantic_threshold_type`, and `semantic_threshold`.
2. Document chunks metadata JSON files output a structured schema containing both `"parents"` and `"chunks"` (representing children with a `"parent_id"` reference).
3. The vector database indexes child chunks only, keeping their size optimized.
4. During `/query` and `/query/stream`, retrieved child chunks are dynamically swapped with their parent chunk text contents before feeding the context blocks to ChatGroq.
5. All automated unit and integration tests run successfully.
