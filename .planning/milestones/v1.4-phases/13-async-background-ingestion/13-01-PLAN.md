# Plan 13-01: Decouple document upload ingestion to background task with polling endpoint

## Goal
Implement async document parsing, chunking, and indexing pipeline using FastAPI `BackgroundTasks`, enabling `/upload` to return HTTP 202 immediately, and implement `GET /upload/{job_id}/status` to poll task execution state.

<threat_model>
- **Threat**: Cross-tenant data leakage via job status polling.
- **Mitigation**: The job status router checks if the requested job's `user_id` matches the authenticated `current_user["id"]`. It returns `403 Forbidden` if they differ, and `404 Not Found` if the job does not exist.
- **Threat**: Ingestion failure leaves corrupted partial index files on disk.
- **Mitigation**: On failure, the background runner synchronously triggers a hard cleanup, unlinking the temp raw file, deleting chunk metadata JSON, and calling `vector_manager.delete_document()`.
</threat_model>
