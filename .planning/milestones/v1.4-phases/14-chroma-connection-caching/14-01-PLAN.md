# Plan 14-01: Build thread-safe Chroma connection cache, integrate in vectorstore.py, routes, and tests

## Goal
Implement a thread-safe, bounded LRU cache for Chroma client instances to avoid repeated open/close overhead on SQLite files, evict clients cleanly on document deletion/reindexing, and register an app shutdown hook to close cached connections.

<threat_model>
- **Threat**: Cross-tenant data leakage if clients are cached incorrectly.
- **Mitigation**: The cache key uniquely combines `(user_id, document_id)`. The lookup path strictly partitions connections by user IDs, preventing cross-tenant access to cached databases.
- **Threat**: OS file descriptor resource exhaustion or memory bloat from keeping too many clients open.
- **Mitigation**: Enforce a maximum capacity limit (e.g. 100) using a bounded LRU cache structure. When capacity is exceeded, the least recently used client is evicted and closed.
</threat_model>
