# Plan 22-01: Conversational Endpoints & SSE Streaming

## Goal

Integrate chat history loading, query condensation, dynamic title generation, and message transcript persistence into `/query` and `/query/stream` routes.

## Requirements Addressed

- **MEM-04**: Conversational retrieval in `/query` endpoint.
- **MEM-05**: Conversational retrieval in `/query/stream` endpoint.
- **MEM-06**: Dynamic title generation for sessions.

## Success Criteria

1. `POST /query` and `POST /query/stream` accept `session_id` and check session existence/ownership.
2. Follow-up queries are rewritten using session context before retrieval, reranking, and generation.
3. Message logs are persisted chronologically in SQLite, including citation metadata for the assistant.
4. Custom titles are dynamically generated on the first question turn.
5. All automated unit and integration tests run successfully.
