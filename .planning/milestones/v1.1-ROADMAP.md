# Roadmap: Document RAG REST API (v1.1)

## Overview

This roadmap details the refactoring phases to transition the Document RAG REST API to standard, modern LangChain Expression Language (LCEL) chains, native retrievers, and clean codebase standards.

## Phases

- [x] **Phase 6: LangChain Component Refactoring** - Transition to native Retrievers, ChatPromptTemplates, StrOutputParsers, and declarative LCEL chains.
- [x] **Phase 7: Codebase Standardization & API Error Boundaries** - Standardize absolute imports, unify exception handling, format PEP8 styling, and verify integration checks.

## Phase Details

### Phase 6: LangChain Component Refactoring

**Goal**: Transition retrieval and generation pipelines to modern, declarative LangChain LCEL structures.
**Mode**: refactor
**Depends on**: Phase 5 (v1.0 completion)
**Requirements**: LCEL-01, LCEL-02, RET-01
**Success Criteria** (what must be TRUE):

  1. Q&A answering pipeline in `qa.py` utilizes declarative LangChain Runnables/LCEL chains (`setup_retriever | prompt | llm | output_parser`).
  2. Document retrieval is triggered using standard `vectorstore.as_retriever()` components.
  3. LLM generation leverages `ChatPromptTemplate` and `StrOutputParser` for clean string responses.

**Plans**: 1 plan
Plans:

- [x] 06-01: Refactor Q&A retrieval and prompt-inference to use native LangChain retrievers and LCEL chains.

### Phase 7: Codebase Standardization & API Error Boundaries

**Goal**: Enforce strict code quality conventions, absolute module imports, and clean REST API error responses.
**Depends on**: Phase 6
**Requirements**: CLEAN-01, CLEAN-02, CLEAN-03
**Success Criteria** (what must be TRUE):

  1. All imports in routes and core modules conform to absolute `from backend.app.*` path patterns.
  2. Internal database, parsing, and LLM connection exceptions map to structured HTTP exceptions in route handlers.
  3. Entire pytest verification suite runs and passes successfully.

**Plans**: 1 plan

Plans:

- [x] 07-01: Standardize absolute imports, unify exception boundaries, and clean up formatting.
